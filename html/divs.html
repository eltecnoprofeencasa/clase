Tutorial de Divs en HTML

¿Qué es un div?

Un <div> es un contenedor genérico en HTML que se utiliza para agrupar elementos y aplicar estilos o diseños. No tiene un significado semántico específico, por lo que es muy flexible.

Este es un ejemplo de un <div>.

Atributos más usados en divs

Los <div> pueden tener varios atributos, pero los más comunes son:

  • class: Para asignar una clase y aplicar estilos CSS.
  • id: Para identificar un div de manera única.
  • style: Para aplicar estilos directamente en el elemento.
Este es un <div> con el atributo style aplicado directamente.

Colocar divs en horizontal

Para colocar varios <div> en horizontal, puedes usar propiedades como float, display: inline-block, o flexbox.

1. Usando float

La propiedad float permite que un elemento flote a la izquierda o derecha de su contenedor. Es importante usar un clearfix para evitar problemas de diseño.

Div 2 con float: left.

2. Usando display: inline-block

La propiedad display: inline-block permite que los elementos se coloquen en línea pero manteniendo las propiedades de bloque, como width y height.

Div 1 con display: inline-block.
Div 2 con display: inline-block.
Div 3 con display: inline-block.

3. Usando flexbox

Flexbox es una técnica moderna para crear diseños flexibles y responsivos. Con display: flex, los elementos se colocan automáticamente en horizontal.

Propiedades CSS importantes para divs

Algunas de las propiedades CSS más usadas con <div> son:

  • width: Define el ancho del div. Puede ser en píxeles (px) o porcentaje (%).
  • height: Define la altura del div.
  • margin: Controla el espacio exterior alrededor del div.
  • padding: Controla el espacio interior dentro del div.
  • background-color: Define el color de fondo del div.
  • border: Añade un borde alrededor del div.
