Introducción

Las pseudo-clases en CSS permiten aplicar estilos a elementos HTML en función de su estado o posición. Este tutorial cubre algunas de las pseudo-clases más comunes.

:first-child

La pseudo-clase :first-child se aplica al primer elemento hijo de un elemento padre.

  • Elemento 1
  • Elemento 2
  • Elemento 3 (destacado)

<ul class="lista">
<li>Elemento 1</li>
<li>Elemento 2</li>
<li class="destacado">Elemento 3 (destacado)</li>
</ul>

.lista li:first-child { color: blue; }
.parrafo p:first-child { font-weight: bold; }
.span span:first-child { font-size: 1.2em; }
