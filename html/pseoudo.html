Introducción

Las pseudo-clases en CSS permiten aplicar estilos a elementos HTML en función de su estado o posición. Este tutorial cubre algunas de las pseudo-clases más comunes.

Enlaces (:link, :visited, :hover, :active)

Estas pseudo-clases se utilizan para estilizar enlaces en diferentes estados:

  • :link: Enlaces no visitados.
  • :visited: Enlaces visitados.
  • :hover: El cursor está sobre el enlace.
  • :active: El enlace está siendo clickeado.
Enlace no visitado
Enlace visitado (ejemplo.com)
<a href="#">Enlace no visitado</a>
<a href="https://www.ejemplo.com" target="_blank">Enlace visitado</a>

a:link { color: green; }
a:visited { color: red; }
a:hover { color: orange; }
a:active { color: blue; }

Citas (:lang)

La pseudo-clase :lang se utiliza para aplicar estilos a elementos en función del idioma del contenido.

Aquí empieza un texto y lo siguiente es en español: Esto es una cita en español.

Aquí empieza un texto y lo siguiente es en inglés: This is a quote in English.

<q lang="es">Esto es una cita en español.</q>
<q lang="en">This is a quote in English.</q>

q:lang(es) { quotes: "«" "»"; }
q:lang(en) { quotes: '"' '"'; }

Primera letra (::first-letter)

La pseudo-clase ::first-letter se utiliza para estilizar la primera letra de un texto.

Este párrafo tiene la primera letra en rojo.

<p>Este párrafo tiene la primera letra en rojo.</p>

p::first-letter { color: red; }
