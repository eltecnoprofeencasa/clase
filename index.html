Breve historia de HTML

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Fue creado por Tim Berners-Lee en 1991 mientras trabajaba en el CERN. La primera versión de HTML era muy básica y permitía solo la creación de documentos simples con enlaces. Con el tiempo, HTML ha evolucionado significativamente, incorporando nuevas etiquetas y funcionalidades que permiten la creación de páginas web más complejas y dinámicas. Hoy en día, HTML5 es la última versión y ofrece soporte para multimedia, gráficos y aplicaciones web modernas.

Los códigos HTML consisten en etiquetas que definen la estructura y el contenido de una página web. Algunas etiquetas comunes incluyen <h1> para títulos, <p> para párrafos y <a> para enlaces.
